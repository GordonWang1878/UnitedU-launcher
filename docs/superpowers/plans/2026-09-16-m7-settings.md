# M7 Implementation Plan — 设置体系重做 + 恢复默认 + 语言 + 待机接线 + 关于/更新 + 首次引导

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把设置页改成两栏 + 首页透明叠加实时预览,齿轮菜单归并四项,加恢复默认 / 语言 / 待机接线 / 关于与检查更新 / 首次引导,并交付发布脚本与用户 README。

**Architecture:** `MainActivity` 的界面从「if/else 链互斥替换」改成**分层叠加**:底层 `HomeScreen(previewing)` 常驻,其上按需叠 `SettingsScreen`,再上叠各选择器/导入页/默认桌面卡;`EditScreen` 仍独占。每一层各自持有焦点账本(铁律 3),下层在有上层时 `canFocus=false` 并让路(铁律 4/6)。设置页由 `SettingsModel`(纯 Kotlin:分组、行、选项、当前值、动作)驱动,二维焦点账本 `(group, row)`;主题色经 `LocalThemeColors`(theme-cleanup 分支)全局流动。检查更新 = 纯函数解析 `latest.json` + `HttpURLConnection` 下载 + SHA-256 + 现有 `ApkInstaller`。

**Tech Stack:** Kotlin 2.0、Compose(BOM 2024.10.01,无 AppCompat)、JVM 单测(JUnit4,无 Robolectric)、模拟器 `unitedu-tv`(emulator-5554)。

**Spec:** `docs/superpowers/specs/2026-09-16-m7-settings-design.md`(§0 决策表是权威;冲突以 spec 为准)。

**Baseline:** main 合并 `theme-cleanup` 分支之后(已删主题化壁纸;`LocalThemeColors` 已存在;设置控件 11 个)。执行前 `git merge-base` 确认。

## Global Constraints

- 铁律七条(`CLAUDE.md`):**绝不用可滚动容器**;焦点落地只信 `isFocused`;每个浮层自己负责焦点恢复且 `FocusRequester` 逐项挂;守卫必须同时是 key;不用一次性布尔闩;目标与当前位置分开、从 `ON_PAUSE` 冻结。
- 文案全部进 `strings.xml` 三份(`values/`、`values-en/`、`values-zh-rTW/`),key 三份一致,无重复。
- 不引入新依赖(AppCompat、OkHttp、协程以外的库一律不加);网络只用 `HttpURLConnection` + https。
- `settings.json` / `layout.json` / `titles.json` 向后兼容:旧文件必须能读,未知 key 忽略。
- 零回归:`previewing=false` 首页像素不变;默认主题色像素不变(对比方法同 M4 T6:截图前把焦点放到齿轮,只允许时钟区差异)。
- 每个任务:单测绿(`gradle --no-daemon testReleaseUnitTest`)、`assembleRelease` 绿、模拟器验证项写进报告并附截图;提交带 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`;不 push。
- 主线程不做磁盘 IO(已有例外:`SettingsStore` 的亚毫秒级扁平 JSON 写)。
