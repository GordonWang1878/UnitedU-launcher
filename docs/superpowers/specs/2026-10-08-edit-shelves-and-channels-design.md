## 0. 一句话

编辑桌面改成全屏「货架」:每一行是一层玻璃架子,行能做的事直接摆在架子顶部;最后一层「新的一行」里选「应用行 / 频道」。频道行(其它应用推送的节目)只能从这里亲手加,默认一行都没有。

## 2. 编辑桌面(货架)

### 2.1 页面结构
- **顶部**(左缘 58 dp):「编辑桌面」(`Type.headline`)+ 概况小字「N 行 · N 个应用 · N 个频道」;右边三个按键提示:`确定` 拿起卡片、`↑` 行操作、`返回` 完成。原来的整段说明删除。
- **货架**:从上往下排,左右各留 40 dp,圆角 20 dp。焦点所在那一层的顶边对齐屏幕上方约 1/3(焦点线),其余层按累计高度排开;纵向位移自己算(`offset` + `animateDpAsState` + `wrapContentHeight(unbounded = true)`,铁律 1)。
- **应用架子**:顶部一行 = 行图标 + 「N 个应用」+ 右侧操作胶囊(添加应用、换图标、上移〔不是第一层时〕、下移〔不是最后一个内容层时〕、删除〔应用行多于 1 行,或这是频道行时〕);下面是应用卡(固定中档 122 × 68.6 dp,不跟「卡片大小」设置),行尾不再有「+」。空架子在卡片位置放一张「添加应用」方块。
- **频道架子**:顶部 = 频道图标 + 「应用名 · 频道名」+ 小标签「频道」+ 操作胶囊(上移、下移、删除);下面是海报预览(按比例,高 68.6 dp,最多画到架子右缘,**不可聚焦**)。没内容写「暂无内容」;没授权写「需要重新授权」并多一颗「重新授权」胶囊。
- **新的一行**:永远是最后一层,虚线边框,里面两张选择卡「应用行」「频道」,各一句说明(见 c2)。

### 2.2 焦点
- 上下键按固定顺序逐格走:第 1 层胶囊 → 第 1 层卡片 → 第 2 层胶囊 → 第 2 层卡片 → … → 新的一行。频道架子只有胶囊那一格。
- 从卡片按上 → 本层胶囊里离得最近的那颗(按水平中心);从胶囊按下 → 本层卡片里离得最近的那张。左右到头 `Cancel`。
- 账本(取代现在的「行 + 列,列 = apps.size 时是 +」):目标 = `(shelf, zone ∈ {CHIPS, CARDS, NEW}, index)`,三个分量各自与「当前位置」分开(铁律 5),`ON_PAUSE` 起冻结。每个可聚焦节点逐项挂 requester(铁律 3 的实现约束),定位效果只信目标自报 `isFocused`(铁律 2),`holder == null` 看门狗(3 帧宽限、60 帧封顶,守卫与 key 同一个量,铁律 6)。
- 动作后的落点:上移 / 下移 → 跟着这一层走,落它的同一颗胶囊;删除 → 落上一层的胶囊(删的是第一层落新的第一层);新建应用行 → 新架子的「添加应用」方块;加频道 → 新频道架子的第一颗胶囊;添加应用 → 新卡;从浮层返回 → 打开它的那颗胶囊 / 那张卡。

### 2.3 卡片操作(照 Google TV「Arrange your Apps」,`docs/screenshots/edit-ref/gtv-04…06`)
- **确定 = 拿起**:卡片抬起(放大 1.08 + 阴影)、四周出现方向箭头。左右在本行换位;上下搬到相邻的**应用**架子(跳过频道架子;前后都没有应用架子就不动);确定放下(写盘),返回取消(回原位、不写盘)。沿用现在的搬运模式实现(`carry`),只是入口从菜单改成确定键。
- **长按 / 菜单键 = 卡片菜单**:换卡片图、移出这一行(`GearMenu` 两颗胶囊,与现在的卡片菜单同一套焦点)。**菜单键在编辑页的含义从「退出编辑页」改成「卡片菜单」**(焦点不在卡片上时菜单键不做事);退出一律按返回。
- **删除一行**:空行、频道行直接删;有应用的行弹确认页(默认在取消,现有 `ConfirmDialog`)。

### 2.4 新的一行
- 「应用行」→ 在最后插入空应用架子,焦点落它的「添加应用」方块。
- 「频道」→ 打开选频道页(§3.1),选好后在最后插入频道架子。
- 某类已满 5 行:那张选择卡变暗、写「已满 5 行」,确定不响应(仍可聚焦,好让人看到原因)。
- 新行一律插在最后,换位置用上移 / 下移;原行菜单里的「在下方新建一行」随行菜单一起取消。

### 2.5 视觉与动效
- 背景:当前壁纸缩到 1/8 做一次模糊,缓存为位图,之后每帧只画它;上盖约 72% 深色。无壁纸时纯 `MenuBg`。A95L 不实时算模糊。
- 架子:白 5.5% 底 + 白 7% 细边;焦点层白 10% 底 + 白 14% 边 + 阴影;非焦点层整层约 60% 不透明(只在绘制阶段读,不影响可聚焦性)。
- 操作胶囊:28 dp 高、14 dp 圆角、白 8% 底、12 sp;聚焦填主题 accent、按亮度选对比字色、放大 1.08。与设置页胶囊同一语言(`ShellCapsule` 的取色逻辑复用)。
- 卡片焦点样式沿用首页(放大 + 描边 + 柔光)。
- 动效:换层时架子亮度与整页位移同走 200 ms(`FastOutSlowIn`);拿起 / 放下 150 ms;沿用现有时长档,不新造曲线。
- 进出编辑页、浮层开关的淡入淡出沿用 `FadeSwitch` / `OverlayStack`(残影让路规则照旧)。

### 2.6 不变的
- 入口(设置 → 布局 → 编辑桌面;空桌面的「编辑桌面」胶囊)与退出(返回)不变;每一步即时落盘(`persist` + `layoutWrites`)不变。
- 首页不改版式;「添加应用」页(`AppPicker`)、行图标页(`RowIconPicker`)、换卡片图页沿用,只是入口从行菜单 / 卡片菜单改到胶囊 / 卡片菜单。
- 「只画已装、可启动的包」(R67)与看得见的列号口径不变。

## 3. 频道行

### 3.1 选频道页(`ChannelPicker`)
- 整屏两栏,版式与焦点机制照 `AppPicker`:左边页名「添加频道」+ 说明「UnitedU 会读取电视上各应用提供的频道,只在本机显示,不上传。」;右边一列,每项 = 应用图标小卡 + 「应用名 · 频道名」,已在桌面上的不列。
- 没有 `android.permission.READ_TV_LISTINGS` 先弹系统授权窗;拒绝 → 说明 + 「去系统设置开启」;没有任何频道 → 「暂时没有应用提供频道 / 打开过一次的视频应用才会提供」+「返回」。
- 进页(已授权)时给声明了 `INITIALIZE_PROGRAMS` 接收器、还没通知过的包发一次显式广播(按包名 + versionCode 记在 `channel-init.json`);列表随 TvProvider 变化自动补上(ContentObserver),焦点按 id 重定位。
- 是编辑页 `OverlayStack` 里的新一层,状态并进 `overlayOpen`(铁律 6);残影让路。

### 3.2 首页频道行(沿用 `2026-10-08-channel-rows-design.md` §2.3、§4,R164-4)
- 行头卡片上方「应用名 · 频道名」;卡高 110 dp、宽按 `poster_art_aspect_ratio`;按 `weight` 降序最多 12 张;焦点行每张卡下标题 + 一行元数据(季集 / 时长;不重复「应用 · 频道」);确定 = `intent_uri` 启动,失败打开应用;长按不做事;没内容 / 没授权整行不画。
- 纵向位移改成逐行高度累计(应用行之间逐像素不变,单测先写);横向位移加「每张卡宽度列表」版本。

### 3.3 数据、海报、权限(沿用原稿 §3、§7)
- layout.json:频道行 = `{"icon":"tv","apps":[],"channel":{"pkg","key","name"}}`;`LayoutRow` 加默认值字段 `channel: ChannelRef? = null`;`key` = `internal_provider_id`,缺省按 `display_name`;`parse` 要求至少一行应用行。
- 读 `channel`(`?package=`)与 `preview_program`(按频道),显式投影、不用 selection、只要 `TYPE_PREVIEW`、不看 `browsable`;ContentObserver 500 ms 去抖 → `channelsRevision`;`SecurityException` = 需要重新授权。
- 海报:`content://` / `android.resource://` 走 ContentResolver,`https://` 走 `HttpURLConnection`,解码到卡片像素,16 MB `LruCache`,只加载焦点行 ± 1;失败画深色底 + 标题。
- 清单加 `READ_TV_LISTINGS`;`registerForActivityResult(RequestPermission)` 在 `MainActivity.onCreate` 注册。
- 应用卸载(`PACKAGE_FULLY_REMOVED` / 启动缺包清理)→ 删它的频道行。

## 4. 数量

应用行 1–5 行(只数应用行);频道行 0–5 行(`MAX_CHANNEL_ROWS`);首页每个频道行最多 12 张卡。

## 5. 要顺手修的旧路径

- `Move.kt` `moveCard` / `moveInLayout`:上下搬运跳过频道行。
- 所有应用页「加到桌面… → 选一行」与 `AppsPage.rowAppNames`:只列应用行,下标映射回 layout 下标。
- `pruneMissingPackages` / `pruneUninstalled` 处理频道行。
- `addRowBelow` / `deleteRow` 的判据按应用行数 / 频道行数分开(新行改成追加在末尾)。
- `MainActivity` 的菜单键分支:编辑页里不再「退出编辑页」,改由编辑页处理(卡片菜单)。

## 6. 焦点表(CLAUDE.md「谁负责恢复」表要改写的行)

- 「编辑页」一行重写成货架账本(§2.2);「编辑页的行菜单」一行删除(行菜单取消);新增「选频道页」一行、「首页频道行」并入首页一行。
- 搬运模式(拿起)仍不是浮层,焦点始终在被搬的卡上;卡片菜单、确认页、各选择页仍是 `OverlayStack` 浮层,各自负责恢复,编辑页看门狗让路。

## 7. 测试

- **单测**:§2.2 的焦点顺序(给定货架列表 → 上下键序列的落点)、动作后落点、行数判据、`moveCard` 跳过频道行、layout 频道行往返与「全是频道行当损坏」、缺包清理、频道匹配、海报宽度、首页纵向累计 top(应用行之间与现状一致)、节目排序截断。
- **e2e**:`j_edit.py` 按新交互重写(拿起 / 放下 / 取消、胶囊操作、删除确认、新的一行);新增 `j_channels.py`(带代码的夹具发布 APK;加频道 → 授权 → 首页出现 → 启动 → 节目变化 / 卸载 → 撤销授权)。
- **性能**:模拟器量编辑页(10 层 + 模糊背景)与首页(5 应用行 + 5 频道行 × 12)帧时间;真机由 Gordon 随正式版在电视上看。

## 8. 不做(本轮)

继续观看;自动播预告片;长按频道卡菜单;频道 logo;设置总开关 / 频道管理页;审批 `browsable`;磁盘图片缓存;首页本身的就地编辑(方案 A)。

## 9. 风险

- 编辑页的焦点账本整体重写,是七条铁律最容易复发的地方;按 §2.2 逐条落实,单测先行。
- 首页纵向位移从等高改成累计。
- 国行频道数据量只能在电视上确认(随正式版看)。
