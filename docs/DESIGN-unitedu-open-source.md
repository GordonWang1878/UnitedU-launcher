| 项 | 决定 |

## 2. 首页

- **应用行**:1–5 行,编辑分栏页管理——行尾「+」打开**行菜单**:添加应用 / 重命名此行 / 更换此行图标 / 此行上移 / 此行下移 / 在下方新建一行 / 删除此行(不适用的项不列出,如第 1 行没有「上移」、已 5 行没有「新建」、非空行删除前先弹确认框)。每行:名字(自由改,系统输入法,清空 = 不改)、图标(12 个内置 id:影片/电视/直播/音乐/游戏/儿童/工具/学习/运动/资讯/相册/应用,4×3 网格选择器 `RowIconPicker`;没有 `"icon"` 字段的旧行按名字回落匹配 [VIDEO→影片、LIVE→电视、MUSIC→音乐,其余→电视],渲染与图标 id 化之前逐像素相同;改名时如果这行还没存过图标,会把当前回落显示的图标顺手存下来,不会因为改名跳成别的图标)、应用列表。数据仍是 `layout.json`(已数据驱动),`"icon"` 字段可选。
- **卡片**:16:9,圆角 8dp(tv-material Card 默认);聚焦 1.1 倍 + 3dp 描边,无光晕,无标题为默认。**标题开关为全局**:关了自定义标题也不显示(Gordon 定)。**大小三档 = 每行 8 / 6 / 5 张**,卡片宽由张数算出(M8:(844 − 20×(N−1))/N,边距 58、间距 20,`HomeLayout`),行高、编辑页布局按档位缩放。
- **首页结构**:壁纸全屏 + 大字时钟(左上,84sp)+ 应用行从下三分之一起、焦点行锚定、底部 scrim;右上 pill 组(设置 / 屏保);无邻行压暗。
- **上下键同列落点**(2026-09-18 Gordon A95L 验收后定,取代 Projectivy 式「每行记住自己的列」):按上下键落到邻行同一列,邻行更短就落它最后一张;从菜单 / 设置页 / 别的应用回来仍回到离开前那一格,那是另一套记忆。
- **卡片图优先级**:自定义图 `library/cards/<包名>.*` → leanback banner → **无横幅回落 = 图标居中放在取自图标主色的纯色 16:9 底上,并自动显示标题**(标题开关关着时也不显示,遵循全局规则)。
- **输入源行**:可开关,默认关。走标准 `TvInputManager` 枚举,跨品牌;HDMI-CEC 子设备与其所在端口去重(留子不留父,子设备名比端口名有用,只看一层父子关系)。长按输入源卡 → 菜单(打开 / 改名 / 隐藏,顺序如此);改名复用「修改标题」对话框,存进 `titles.json`(key = 输入 id,清空 = 恢复系统名,与卡片改名同一条路);隐藏存进新文件 `hidden-inputs.json`(`{"<输入 id>":"hidden"}`,与卡片标题一样不被「恢复默认」清掉),隐藏后卡片立即消失。设置页「布局」组在「输入源行」开关下有一行「恢复隐藏的输入源」(有隐藏项时才显示,标注隐藏数),按下一键全部恢复;不做逐项管理列表。全部隐藏后输入源行本身也消失,与「没有输入」走同一条路,恢复后回来。**多个调谐器合并成一张「电视」**(A95L 真机验收后补定,spec §0-19):调谐器类输入(非透传)不止一个时只显示一张——id 不含 analog 的优先,同类按 id 取第一个(A95L 上留索尼 DVB 数字调谐器,去掉联发科模拟调谐器);点调谐器卡打开的本来就是系统通用频道列表、不分是哪一个,两张「电视」效果完全一样。
- **新装应用**:不自动出现。编辑分栏页「添加应用」列表标「新」,首页角落小字「有 N 个新应用」。
- **长按卡片菜单**(Gordon 定):
  ```
  打开应用
  卸载应用            ← 走系统卸载确认页;卸载完成后卡片自动消失
  ─────────
  修改标题            ← 改卡片显示名,不改应用;系统输入法,不限 ASCII
  更改图标            ← 现有 ImagePicker,从 library/cards/ 选
  移动位置            ← 见下
  从当前分类移除
  ```
- **移动位置**:进入**首页原地移动态**——被移动的卡保持聚焦(3dp accent 描边,与聚焦描边同粗但换色以区分「搬运中」),屏幕底部一行提示「← → 移动 · ↑ ↓ 换行 · 确定 放下 · 返回 取消」。左右与同行邻卡换位(到头不动);上下移到相邻的**首页可见应用行**的同一列(越过行尾则落行尾;跳过输入源行;目标行已经有这张卡时原地不动,不合并、不跳过下一行)。确定键**松开**才放下(长按确定无反应,避免与长按菜单的长按检测冲突)并写盘,只重写可见顺序变了的行,没动过的行原样保留(未安装的包留在原行、排在可见包之后);返回、按 HOME、进待机、任何浮层要打开,一律等同取消、原样放回。移空的行在首页随即消失(与今天空行不显示一致),取消时复原。原地移动没有浮层,由首页自己的焦点账本(还原效果 + 看门狗)以被搬的卡为目标,按 `launcher/README.md` 铁律实现,见 CLAUDE.md 焦点责任表「首页原地移动态」一行。**编辑页里同一套搬运,空行也是落点**(A95L 真机验收后补定,2026-09-20):编辑页卡片菜单原来的「往左移 / 往右移」换成一项「移动位置」,键位、确定松开放下、长按无反应、返回取消、相邻行已有同一应用不动,都与首页相同;对象是 layout.json 的行——新建的空行也能搬进去(首页不显示空行,首页搬运进不去),源行被移空照样留在编辑页;离开编辑页、退到后台 = 取消。见 CLAUDE.md 焦点责任表「编辑页」一行。

## 3. 壁纸、主题、时钟

- **壁纸**:素材来自壁纸库 `library/wallpapers/`;设置项「**壁纸自动切换**」关 / 5 分 / 30 分 / 每天(2026-09-19 由「轮播间隔」改名,「轮播」一词留给屏保);复用屏保「进入时重扫目录」逻辑。
- **主题化壁纸开关**:已删除(2026-09-16 Gordon:用户要的是原图;与「跟随壁纸主色」并存易混淆)。壁纸只保留 模糊、亮度 两个滑块(亮度 −50…+50%,0 = 原片,负压暗、正提亮;2026-09-16 真机调参后由「压暗 0–100」改成双向),`ColorMatrix` CPU 离线处理,结果按「源文件 + 参数」缓存;壁纸本身**不染主题色**。
- **主题色**:9 个预设,默认 Material 紫 #D0BCFF(M8),其后是白 #F5F5F5、黑 #1A1A1A 两个基础色(2026-09-18 Gordon 定;黑给浅色照片壁纸用,不做保护),再是原六个+ **「跟随壁纸主色」**开关(`Palette` 库)。主题色驱动**全部界面**的强调色(2026-09-16 全面接线;M8 起首页改经 tv-material 组件,落点随之调整):经 `LocalThemeColors` 一条线,**accent** 驱动首页的行标题 / 行图标 / hero 大字时钟 / 顶栏 pill 图标(M8),以及设置页分组标题;**highlight** 只剩二级界面的标题、焦点条、选中段、滑块填充、光标、选择器标签——首页不再读它;金预设下逐位等于接线前的香槟白 / 香槟金。现有 45 处颜色字面量收进 `Theme.kt` 一个调色板对象。不做取色器。
- **时钟**:M8 起是 hero 大字时钟,不在顶栏;12/24 小时跟系统;日期显示开关;星期语言跟系统语言。不做天气、不做网络状态图标。

## 4. 待机与屏保

**现状机制**(M5 起,改动前必须懂):`MainActivity` 只持有一个 `StandbyFlags`(`idle` + `screensaverActive` 两个布尔量,构造函数钉死「屏保 ⇒ 待机」)。纯函数 `standbyPlan(待机时长, 屏保启动)` 给出两个时刻(都从最后一次按键算),计时效果先写待机、到点在 IO 线程查图库非空再写屏保;首页「屏保」按钮直接写屏保(图库空时退为待机,「不淡出」时空操作);任意键回正常,那一下被吞。轮播归进程级单例 `ScreensaverPlayer`(扫描、下标、唯一一份换图计时、引用计数),桌面屏保层与系统屏保 `UnitedUDream` 都只读它,所以系统屏保从桌面那一张接着播。系统屏保(`screensaver_enabled=0`)与 63 分钟灭屏(`screen_off_timeout`)是 Gordon 用 adb 手设的,产品用户没有。

**术语**(2026-09-19 Gordon 定,全界面统一用这些词):
| 词 | 是什么 | 素材 / 设置项 |
|---|---|---|
| 壁纸 | 首页最底层的背景图,首页开着就一直在 | 壁纸库;「壁纸自动切换」 |
| 待机 | UnitedU 首页无人操作达「待机时长」后进入的状态:卡片行、底部渐变、右上按钮淡出,留什么由「待机显示」定。**不是电视的关屏待机** | 待机时长、待机显示(时钟 / 全黑 / 不淡出) |
| 自定义屏保 | 待机之后仍无人操作、再过「屏保启动」时间进入的状态:全屏轮播屏保图库,左上保留大字时钟(淡阴影) | 屏保图库;「屏保轮播设置」(换图间隔) |
| 系统屏保 | 电视系统的屏幕保护程序,任何应用里无人操作都会触发;时长归系统设置管 | UnitedU 经 `DreamService` 登记为其中一项,放同一个屏保图库 |

**状态模型**(2026-09-19 Gordon 定):正常 →(无操作达「待机时长」)→ 待机 →(仍无操作,再过「屏保启动」时间,且屏保图库非空)→ 自定义屏保。三个状态**互斥、先后发生**,任一时刻只处在一个;任意键回到正常,那一下按键只负责唤醒。系统屏保是系统自己的计时线,可能在任何时刻盖上来(UnitedU 不持有屏幕常亮);若选的是 UnitedU,就从当前照片接着播。M5 已按这条模型实现(见上「现状机制」)。2026-09-18 版把「屏保图库轮播」做成「待机显示」第四个选项,与本模型冲突,作废。

**设置页「待机与屏保」组(M5)**:
| 行 | 内容 |
|---|---|
| 待机时长 | 关 / 1 / 3 / 5 / 10 分(已有) |
| 待机显示 | 时钟 / 全黑 / 不淡出(已有,不加选项) |
| 屏保启动 | 待机后再过 关 / 1 / 5 / 10 / 30 分,默认 5 分(新增) |
| 屏保轮播设置 | 30 秒 / 1 分 / 5 分(新增;现在写死 30 秒) |
| 屏保图库 ▸ | 看图;长按缩略图 →「删除」→ 确认框(手机上传页本来也能删) |
| 系统屏保 ▸ | 跳系统屏保设置页(`Settings.ACTION_DREAM_SETTINGS`,解析不到退到系统设置首页) |

**M5 其余决定**(2026-09-18 定,2026-09-19 按新模型改写):
- 自定义屏保与系统屏保画面一致:全屏轮播 + 左上大字时钟(淡阴影);共用播放器和播放进度;图库为空时系统屏保黑底 + 时钟。
- 首页「屏保」按钮 = 立刻进入自定义屏保,跳过待机;图库为空时退为进入待机(「不淡出」时空操作)。
- **屏保启动**(2026-09-19 Gordon 同意):按「进入待机后再过多久」算,选项 关 / 1 / 5 / 10 / 30 分,默认 5 分;待机时长为「关」时从最后一次按键算;图库为空时永远不进屏保、停在待机,并在这一行提示。

- **内置 6 张壁纸**:只用 CC0 或明确允许再分发的图,来源写进 `NOTICE`。**不能用**现有资源仓里的图:卓耿烈焰 / 龙石日蚀 / 临冬落日(《权力的游戏》)、沙丘·暮色沙虫(《沙丘》)、阿伽门农(《特洛伊》)是剧照或同人图;`launcher/assets/wallpaper-gold-fog.jpg` 是 Projectivy 默认壁纸的加工品。Gordon 自己电视上照旧用。

- 不做 U 盘导入(SAF 选择器在这台机上 D-pad 走不动,挂载路径各家不同)。
- **不做备份/迁移**(Gordon 定;卸载即丢已解释)。换钥匙那次 Gordon 自己那台由我 adb 备份回灌。

## 8. 工程与发布

- **独立项目、独立机器**:在 Core 上新建仓库,远程 GitHub(公开;这是产品仓库,与「Smart Home 永不设远程」无关)。**不从 Smart Home 拆历史**,需要的代码(焦点处理、ImagePicker、Screensaver、HomeSettingsCard 等)与资源逐文件复制;`launcher/README.md` 的七条焦点铁律复制进新仓库的 CLAUDE.md。TvHome 在 Smart Home 里原样不动。
- **Core 工具链**:JDK 17 / Gradle 8.14.5 / Android SDK 三样在 Core 手装一遍(Hub 的装法与 `dl-ssl.google.com` 绕法同样适用,Core 也在 VLAN 1 经 Surge)。Core 能直连电视 adb(`192.168.1.50:5555`,局域网口),但 Core 的 adb 密钥要在电视上再「一律允许」一次。Hub→Core 无 SSH 通道,Core→Hub 有:设计文档等资料由 Core 侧 `scp hub:…` 拉取。
- **更新通道(Q23)**:发布脚本把 `latest.json`(版本号、更新说明、APK 地址、SHA-256)与 APK **双发**到 GitHub Release 和**腾讯云 COS 公共读桶**(默认域名免备案)。**两份 `latest.json` 不是同一份文件的两次拷贝**:各自的 `apkUrl` 指回**自己那条通道**的 APK(COS 桶里的 `latest.json` 指 COS 的 APK,GitHub Release 里的 `latest.json` 指 GitHub 的 APK),这样走 COS 查到更新的用户下载也留在 COS、不会因为跨到 GitHub 的地址而被墙。应用内「检查更新」手动触发,先查 COS 再查 GitHub;下载后调系统安装器,需声明 `REQUEST_INSTALL_PACKAGES`,用户在系统设置给 UnitedU 一次「允许安装未知应用」。**兜底:上传页支持传 APK 安装**,手机从任何渠道拿到 APK 都能装。
- **签名**:新 release keystore。密码 Gordon 写本地文件、我只读路径;不进仓库、不进聊天。
- **去 adb 依赖**:`RelaunchAfterUpdate` 检测 `SYSTEM_ALERT_WINDOW` appop 未授权时静默跳过;权限声明保留。
- **文案**:全部抽到 `strings.xml`,简 / 繁 / 英三份(现在中英混写在 Kotlin 里)。
- **发布件**:`LICENSE`(Apache-2.0)、`NOTICE`(DM Sans OFL、Material Icons Apache、NanoHTTPD(BSD-3)、ZXing(Apache-2.0)、内置壁纸来源)、面向用户的 README(安装、设默认桌面、上传图片、回退)。
- **首发 v1.0.0-beta**。测试设备 = Gordon 的索尼 A95L + Android TV 模拟器(装在 Core:emulator + TV 系统镜像);README 征集其他品牌社区测试。
- 无崩溃上报;README 教 `adb logcat`。

## 10. 风险

1. **焦点**:长按菜单、原地移动态、设置页、引导页、上传页二维码页都是新浮层/新界面,每个都要按 `launcher/README.md` 七条铁律立焦点账本。这是最大的工作量与回归面。

3. **DreamService 在 Sony 国行能否被选中**未验;不能则退回应用内层,功能不缺但体验差一档。
4. **只有一台真机**:其他品牌的遥控器与输入源枚举行为未知,靠 beta 标签与社区反馈。
