# 设计:UnitedU —— TvHome 开源产品化第一版

> 2026-09-14 一轮 brainstorming(定方向)+ 六轮 grilling(定功能)的共识。决策过程与逐题答案见 `FEASIBILITY-sony-a95l-cn-android-tv-launcher.md` §6.56。
> **状态:设计定稿,未开工。**代码一行未动;开工前先按本文拆实施计划。
> **2026-09-14 补充(Gordon 裁定):UnitedU 是与 Smart Home 里的 TvHome 完全独立的另一个项目。**TvHome(`launcher/`,adb 部署,Gordon 自家电视在用)原样保留、继续使用、不搬不删;UnitedU 在 **Core** 上从零建仓开发,需要什么代码或资源**复制**过去,不做 subtree split、不共享历史。

## 1. 产品定义

| 项 | 决定 |
|---|---|
| 名字 | **UnitedU**(不是 United UI)。网上搜不到同名电视桌面,但未做正式商标检索 |
| 形态 | 开源免费侧载:GitHub Release 放 APK;不上 Play,不进国内应用市场(v1) |
| 许可证 | **Apache-2.0**。选它不选 GPL-3.0 的理由:Apache→GPL 可逆、GPL→Apache 不可逆;GPL 要保商业选项得从首个 PR 起配 CLA;GPL 在国内挡「换皮闭源」只是名义威慑 |
| 第一版用户 | **国行无 GMS 电视**(索尼/小米/TCL 国行)。全球 Android TV / Google TV 留 v2 |
| 一句话卖点 | **零广告、零推荐,只有你放上去的应用。**所有「要不要做 X」先拿这句话判 |
| 联网 | 零联网。唯一例外:用户主动点「检查更新」时查一次更新清单(见 §8 更新通道) |
| 包名 | **`com.uniteduone.launcher`**(2026-09-15 Gordon 定,基于自有域名 uniteduone.com;发布后不可改)。与 TvHome 的 `com.gordonwang.tvhome` 互不覆盖,两者可同时装在 Gordon 的电视上;开发期间他的电视继续跑 TvHome |

## 2. 首页

- **应用行**:1–5 行。每行:名字(自由改,系统输入法)、图标(内置约 12 个 Material 图标里选:影片/电视/音乐/游戏/儿童/工具…)、应用列表。数据仍是 `layout.json`(已数据驱动),行图标改为存图标 id 而非按名字匹配。
- **卡片**:16:9,圆角 40%,无标题为默认。**标题开关为全局**:关了自定义标题也不显示(Gordon 定)。**大小三档 = 每行 8 / 6 / 5 张**,卡片宽由张数算出,行高、光晕、编辑页布局按档位缩放。
- **卡片图优先级**:自定义图 `library/cards/<包名>.*` → leanback banner → **无横幅回落 = 图标居中放在取自图标主色的纯色 16:9 底上,并自动显示标题**(标题开关关着时也不显示,遵循全局规则)。
- **输入源行**:可开关,默认关。走标准 `TvInputManager` 枚举,跨品牌;每个输入可隐藏、可改名(复用「修改标题」)。
- **新装应用**:不自动出现。编辑分栏页「添加应用」列表标「新」,首页角落小字「有 N 个新应用」。
- **长按卡片菜单**(Gordon 定):
  ```
  打开应用
  卸载应用            ← 走系统卸载确认页;卸载完成后卡片自动消失
  ─────────
  修改标题            ← 改卡片显示名,不改应用;系统输入法,不限 ASCII
  更改图标            ← 现有 ImagePicker,从 library/cards/ 选
  移动位置            ← 见下
  从当前分类移除
  ```
- **移动位置**:目标是**首页原地移动态**(卡片抬起,左右换位、上下换行,确定落下、返回取消)。实施顺序:先做「跳编辑分栏页并定位到这张卡」兜底,通了再做原地移动。原地移动是新的焦点模式,必须按 `launcher/README.md` 铁律单独立焦点账本。

## 3. 壁纸、主题、时钟

- **壁纸**:从 `library/wallpapers/` 轮播,间隔 关 / 5 分 / 30 分 / 每天;复用屏保「进入时重扫目录」逻辑。
- **主题化壁纸开关**:已删除(2026-09-16 Gordon:用户要的是原图;与「跟随壁纸主色」并存易混淆)。壁纸只保留 模糊、亮度 两个滑块(亮度 −50…+50%,0 = 原片,负压暗、正提亮;2026-09-16 真机调参后由「压暗 0–100」改成双向),`ColorMatrix` CPU 离线处理,结果按「源文件 + 参数」缓存;壁纸本身**不染主题色**。
- **主题色**:5–6 个预设(金 / 香槟 / 蓝 / 紫 / 石墨 / 绿,取自 2026-09-10 出过效果图的候选)+ **「跟随壁纸主色」**开关(`Palette` 库)。主题色驱动**全部界面**的强调色(2026-09-16 全面接线,原先只到首页光晕、时钟、行标题、齿轮四处):经 `LocalThemeColors` 一条线,accent 接齿轮与设置页分组标题,highlight 接光晕 / 时钟 / 行标题以及各界面的标题、焦点条、选中段、滑块填充、光标、选择器标签;金预设下逐位等于接线前的香槟白 / 香槟金。现有 45 处颜色字面量收进 `Theme.kt` 一个调色板对象。不做取色器。
- **时钟**:12/24 小时跟系统;日期显示开关;星期语言跟系统语言。不做天气、不做网络状态图标。

## 4. 待机与屏保

**现状机制**(改动前必须懂):应用只有一个计时器 `Theme.IdleAfterMs`(3 分钟),`idle` 置真同时触发两件事:卡片与行标题淡出只留时钟;屏保层淡入并每 30 秒(`ScreensaverIntervalMs`)轮播 `library/screensavers/`。屏保库空则只剩壁纸 + 时钟。**不是两个阶段。**系统屏保(`screensaver_enabled=0`)与 63 分钟灭屏(`screen_off_timeout`)是 Gordon 用 adb 手设的,产品用户没有。

**决定**:
- 待机时长可调:1 / 3 / 5 / 10 分 / 关。
- 待机显示内容可选:只留时钟 / 全黑 / 不淡出。
- 屏保开关;屏保间隔可调。
- **屏保实现 = `DreamService` 为主,应用内层兜底**:用户在系统「屏幕保护程序」里选 UnitedU,时长与触发交给系统,任何 App 里都能进;系统选不到第三方 Dream 的机器退回应用内层。两者共用图库与轮播代码。**待验:Sony 国行的屏保选择页能否列出第三方 Dream**(09-14 电视不在线,未验)。

## 5. 素材入口

- **内置 6 张壁纸**:只用 CC0 或明确允许再分发的图,来源写进 `NOTICE`。**不能用**现有资源仓里的图:卓耿烈焰 / 龙石日蚀 / 临冬落日(《权力的游戏》)、沙丘·暮色沙虫(《沙丘》)、阿伽门农(《特洛伊》)是剧照或同人图;`launcher/assets/wallpaper-gold-fog.jpg` 是 Projectivy 默认壁纸的加工品。Gordon 自己电视上照旧用。
- **手机上传页**:应用内 HTTP 服务(NanoHTTPD,BSD-3-Clause),屏幕显示地址 + 二维码,手机浏览器打开;支持上传 / 预览 / 删除,三类:壁纸 / 卡片图 / 屏保。**服务只在「导入图片」页打开时运行,退出即停;不设密码。**
- **adb 后门**:`files/library/` 固定路径原样保留,Gordon 的 `tv-sync-resources.sh` 不受影响。
- 不做 U 盘导入(SAF 选择器在这台机上 D-pad 走不动,挂载路径各家不同)。
- **不做备份/迁移**(Gordon 定;卸载即丢已解释)。换钥匙那次 Gordon 自己那台由我 adb 备份回灌。

## 8. 工程与发布

- **独立项目、独立机器**:在 Core 上新建仓库,远程 GitHub(公开;这是产品仓库,与「Smart Home 永不设远程」无关)。**不从 Smart Home 拆历史**,需要的代码(焦点处理、ImagePicker、Screensaver、HomeSettingsCard 等)与资源逐文件复制;`launcher/README.md` 的七条焦点铁律复制进新仓库的 CLAUDE.md。TvHome 在 Smart Home 里原样不动。
- **Core 工具链**:JDK 17 / Gradle 8.14.5 / Android SDK 三样在 Core 手装一遍(Hub 的装法与 `dl-ssl.google.com` 绕法同样适用,Core 也在 VLAN 1 经 Surge)。Core 能直连电视 adb(`192.168.1.50:5555`,局域网口),但 Core 的 adb 密钥要在电视上再「一律允许」一次。Hub→Core 无 SSH 通道,Core→Hub 有:设计文档等资料由 Core 侧 `scp hub:…` 拉取。
- **更新通道(Q23)**:发布脚本把 `latest.json`(版本号、更新说明、APK 地址、SHA-256)与 APK **双发**到 GitHub Release 和**腾讯云 COS 公共读桶**(默认域名免备案)。应用内「检查更新」手动触发,先查 COS 再查 GitHub;下载后调系统安装器,需声明 `REQUEST_INSTALL_PACKAGES`,用户在系统设置给 UnitedU 一次「允许安装未知应用」。**兜底:上传页支持传 APK 安装**,手机从任何渠道拿到 APK 都能装。
- **签名**:新 release keystore。密码 Gordon 写本地文件、我只读路径;不进仓库、不进聊天。
- **去 adb 依赖**:`RelaunchAfterUpdate` 检测 `SYSTEM_ALERT_WINDOW` appop 未授权时静默跳过;权限声明保留。
- **文案**:全部抽到 `strings.xml`,简 / 繁 / 英三份(现在中英混写在 Kotlin 里)。
- **发布件**:`LICENSE`(Apache-2.0)、`NOTICE`(DM Sans OFL、Material Icons Apache、NanoHTTPD(BSD-3)、ZXing(Apache-2.0)、内置壁纸来源)、面向用户的 README(安装、设默认桌面、上传图片、回退)。
- **首发 v1.0.0-beta**。测试设备 = Gordon 的索尼 A95L + Android TV 模拟器(装在 Core:emulator + TV 系统镜像);README 征集其他品牌社区测试。
- 无崩溃上报;README 教 `adb logcat`。

## 9. 不做(v1 明确排除)

最近使用行、收藏夹/文件夹、内容推荐行、取色器、天气、U 盘导入、备份迁移、手机上编辑布局、按时段换壁纸、自动检查更新、Play / 国内市场上架。

## 10. 风险

1. **焦点**:长按菜单、原地移动态、设置页、引导页、上传页二维码页都是新浮层/新界面,每个都要按 `launcher/README.md` 七条铁律立焦点账本。这是最大的工作量与回归面。
2. **卡片三档 × 行数 1–5**:5 行 × 大卡片超出 1080p 可视区,纵向自算位移已有,但编辑页与光晕要按档位重算。
3. **DreamService 在 Sony 国行能否被选中**未验;不能则退回应用内层,功能不缺但体验差一档。
4. **只有一台真机**:其他品牌的遥控器与输入源枚举行为未知,靠 beta 标签与社区反馈。
