## 视觉取舍与理由

1. **左右仍按 1:1 分栏。** 这和 `GearMenu` 的 `Row { weight(1f) / weight(1f) }` 一样,右边胶囊列的中心在 x = 1440 px,与现在的齿轮菜单、长按菜单完全重合。这样每一层切换时,胶囊列的位置一动不动,变的只有内容。
2. **预览区是 400×225 dp(截图里 800×450 px),正好 16:9,等于把整屏按 0.4167 缩小。** 预览在左半屏(480 dp 宽)里左右各留 40 dp。按这个尺寸,中档卡片缩下来约 57 dp 宽,YouTube、Play 这些 logo 还认得出来。如果预览再大,就会顶到胶囊列,左右两块会挤在一起;如果再小,卡片大小的三档之间差别就看不出来,M3 也就没意义了。**预览展示的是整个屏幕,不裁剪**:顶栏、时钟、壁纸都在里面,说「这就是你的桌面」才成立。
3. **预览加 8 dp 圆角(`CARD_CORNER`)和一圈 1 dp、14% 白的描边。** 这圈描边不能省:产品默认没有壁纸,首页底色和菜单的 `MenuBg #0E0E0F` 几乎一样,没有描边的话,预览会融进背景,看上去只剩几张卡片浮在半空(可以拿 `01b-…no-wallpaper.jpg` 放进去对比)。圆角和卡片同一个值,一个界面里不再多出一种圆角。
4. **页名放在预览上方,不放下方。** 上面是一行 16 sp 灰色的路径(「设置」/「设置 · 布局」),下面是 32 sp 的页名(`SETTINGS_TITLE_TEXT`,和 M1 的「设置」同字号)。预览下方留给**有未保存改动时**才出现的说明行:前面一个主题色小圆点,后面写「预览:大 · 按确定保存,按返回不改」。M2 里光标只是停在「卡片大小」上,还没改任何东西,所以不显示这行。这样说明行就是「现在看到的不是已保存状态」的信号,把「确定保存、返回复原」这条规则直接写在屏幕上,不需要用户自己去猜。
   - 没有预览的页面(通用、屏保、手机传输)照 M1 的做法,标题放在左半屏正中。
5. **当前值推荐 M2 的做法:同一行、右对齐、颜色更淡。**
   - M2b 的第二行按 12 sp 写(`MENU_ITEM_HINT_TEXT`),在 1080p 上只有 24 px,坐在 3 米外看,「关 / 开」这种单个字太小。M2 的值和标签一样是 16 sp,只把颜色调淡(未聚焦时是 `MenuItemText` 55% 透明度,聚焦时是黑色 55%),主次靠颜色区分,不靠缩小字号。
   - 所有值排在同一条右边线上,扫一眼就能看完一整列设置,这是两行写法做不到的。
   - 胶囊一直保持 55 dp 单行高,7 项加起来 481 dp,放得进 540 dp 高的屏幕,和第一层节奏一致。
   - 附带一点:M2b 每项只有一个字的值时,算下来也只比 55 dp 高一点点,所以两行写法并不是因为太高才没选,主要问题是字太小。
   - Google TV 系统设置用的是「标题 + 第二行摘要」,这一点和我们的推荐不同。但 Google 的摘要常常是一整句话;我们的值都很短(关、中、40%),同行右对齐更合适。
6. **M3 的选中标记:✓ 放在值所在的位置(右端),未聚焦时用主题色,聚焦时用黑色。** 规则是右端永远表示「状态」:第二层显示值,第三层显示 ✓,可进入的项显示 ›,用户只要学一种读法。焦点(整块填满主题色)和已保存(✓)是两个维度,M3 里两者同时出现在不同的项上,不会搞混。
7. **滑块形态:只有聚焦的那个胶囊变成滑块,胶囊仍是 55 dp 单行。** 内容从左到右是:标签,6 px 高的轨道(已填部分是黑色 78%,未填部分是黑色 16%),22 px 的黑色圆点把手,再加上 `‹ 40% ›`(左右箭头 45% 透明,提示按左右键调节)。未聚焦的滑块胶囊和普通选项胶囊长得一样,只在右端显示数值,整列看起来很安静,光标移上去它才「展开」成滑块。轨道和文字都用黑色,是因为 `contrastingTextColor` 在浅色主题色上选的就是黑色,5 个预设都是浅色,效果统一。
8. **M1 去掉了每项的说明文字。** 现在的齿轮菜单打开了 `showHints`,如果 7 项都带两行说明,高度会超过屏幕;而且这 7 个名字本身就够清楚。

## 用到的真实常量(dp 和 sp 都 ×2 换算成 px)

| 常量 | 值 | 出处 |
|---|---|---|
| `MENU_ITEM_WIDTH` × `MENU_ITEM_HEIGHT` | 268 × 55 dp → 536 × 110 px | `GtvLayout` |
| `MENU_ITEM_GAP` | 16 dp → 32 px | `GtvLayout` |
| `MENU_ITEM_PADDING_H` / `_V` | 24 / 10 dp | `GtvLayout` |
| `MENU_ITEM_TEXT` / `MENU_ITEM_HINT_TEXT` / `MENU_ITEM_HINT_GAP` | 16 sp / 12 sp / 2 dp | `GtvLayout` |
| `SETTINGS_TITLE_TEXT` | 32 sp,行高 ×1.2,Medium 字重 | `GtvLayout` / `GearMenu.MenuBanner` |
| `CARD_CORNER` | 8 dp(预览圆角) | `GtvLayout` |
| `MenuBg` / `MenuItemIdle` | #0E0E0F / #161718 | `GtvTokens` |
| `MenuItemText` / `EmphasisText` / `SecondaryText` | #B0B0B0 / #F5F5F5 / #9A9A9A | `Theme` |
| 淡紫预设(默认)accent | #D4CCE3 | `ThemePresets` |
| 聚焦文字色 | accent 的亮度 > 0.5 时用黑色 | `GearMenu.contrastingTextColor` |
| 字体 | Google Sans Flex(`res/font/google_sans_flex.ttf`)+ 从模拟器 `/system/fonts` 取出的 Noto Sans CJK SC | `Theme.Sans` |

效果图里有三个值是新定的,代码里还没有对应的常量:预览尺寸 400×225 dp、滑块轨道 3 dp 高、把手 11 dp。
