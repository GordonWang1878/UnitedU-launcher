# 外观轮:字体统一、动效优化、UI 提升(2026-09-30,R134–R136)

**目标(Gordon /goal)**:「外观轮:字体统一,动效优化,UI 提升」。

**走法**:先盘点(扫源码里所有字号 / 文字色 / 动画规格,模拟器逐屏截图),再改,再在模拟器 `unitedu-tv`(`-gpu host`)上逐页核对焦点落点、1× 录屏看动效。前后对比与逐帧图在 `docs/screenshots/r135-*`、`r136-*`(对比图是英文界面;`r135-zh-tw-pages.jpg` 是繁体)。英文、简体、繁体各走过一遍。**电视上还没看过**——下面所有「已验证」都指模拟器。

## 盘点结论:不统一的不是字体,是字号、颜色和版式

字体文件本来就只有一套(Google Sans Flex;中文没有自带字形,回落到系统 Noto Sans CJK)。不统一的是它的用法:

| 量 | 改前 | 改后 |
|---|---|---|
| 字号 | 界面代码里写死 15 种(10–32 sp) | 七档 31 / 22 / 17 / 15 / 14 / 12 / 11(另有顶栏时钟 16) |
| 页名 | 设置 31、编辑页 20、引导 26、选图页与对话框 16 | 一律 31 |
| 文字色 | 11 种灰,最暗的 #4A4A4A / #666666 在深色底上对比度约 2:1 | 四档 #F5F5F5 / #B0B0B0 / #9A9A9A / #7E7E7E(最弱 4.8:1) |
| 最小字 | 10 sp(1080p 上字高 20 px) | 11 sp |
| 版式 | 两套并存:整屏深色页,与更早的「屏幕中间小面板 + 半透明蒙版」 | 只有两种整屏版式(见下) |
| 浮层进出 | 只有设置 / 关于 / 所有应用 / 输入源有淡入淡出,其余硬切 | 全部同一套 |

根因是界面分几轮做出来:设置外壳(R69 起)照 Google TV 定了一套规格,更早做的对话框、选择器、引导没有跟着换。所以这一轮的做法不是再发明一套,而是**把已经定案的那一套铺到全部页面**,并用单测钉住不让它再散开。

## R134 字体:七档字号、四档文字色,只此一处

`Type.kt` 是唯一来源;`Theme` 里旧的颜色名字都指过去。每一档用在哪:

| 档 | sp | 用在哪 |
|---|---|---|
| 页名 | 31 | 每个整屏页 |
| 要照抄的一行 | 22 | 扫码页的网址 |
| 分组标题 / 分步说明 | 17 | 「内置 / 我的」、扫码页三步 |
| 标签 | 15 | 胶囊、按钮、列表项、行名、页名上方的小字 |
| 说明 | 14 | 说明文字、卡片名 |
| 图注 | 12 | 缩略图名字、页脚提示 |
| 最小 | 11 | 胶囊第二行、角标、许可声明 |

- 31 / 15 / 11 就是 R109(Gordon 2026-09-28「就这样」)定下的设置页字号,没有新取值;这一轮是把其余页面拉过来。
- 字重只用 Normal / Medium:中文回落字体只有 Regular,Bold 会被系统合成加粗(笔画糊)。
- 「＋」改画图标,不再是全角加号字(粗细随回落字体变)。
- 页名与居中的短说明**均衡折行**:折成两行以上时各行长短接近,末行不会只剩一两个字(繁体引导第 2 步原来折成 12 + 1,第二行只有一个「面」)。行数不变,固定高度的说明块不受影响。
- 防线:`TypeScaleTest` 扫源码——界面代码里不许写死字号、不许用 Bold、不许用别的字体;最弱一档文字色在页面底色上对比度 ≥ 4.5。

## R135 UI:所有页面只用两种版式

1. **左右两栏**:左半屏正中是页名(上方一行小字写「属于谁」,下方写说明或后果),右半屏正中是一列胶囊或一个控件。用于设置各层、关于、输入源、长按菜单,以及这一轮换过来的:确认页、改名页、行图标、添加应用、首次引导、从手机添加。
2. **页头 + 网格**:页名在左上角,操作提示跟在页名右边,下面是整宽网格。用于所有应用、编辑桌面,以及这一轮换过来的三个选图页。

底色一律 `MenuBg`;焦点只有两种画法——胶囊 / 图标格 / 输入框填主题色,卡片 / 缩略图放大 + 描边。

| 页面 | 改前 | 改后 |
|---|---|---|
| 删除 / 删行确认 | 中间小面板,两颗横排方按钮 | 一页菜单:左边问题 + 后果,右边「取消 / 删除」两颗胶囊,默认在取消 |
| 改名 | 中间小面板,细线输入框 | 整屏两栏,胶囊形输入框(聚焦填主题色);空着时淡淡垫着清空后会恢复成的名字 |
| 行图标 | 中间小面板,聚焦画描边 | 右半屏 4 × 3 图标格,聚焦填主题色 |
| 添加应用 | 中间一列,85 % 黑蒙版 | 左边写加到哪一行,右边一列应用 |
| 首次引导 | 蒙版上一列 620 dp 内容,带描边的方按钮横排 | 每步左边说明、右边胶囊;语言那一步四颗胶囊带 ✓ |
| 换壁纸 / 屏保图库 | 一行 3 张 170 dp,蒙版透出首页 | 一行 4 张 196 × 110 |
| 换卡片图 | 一行 4 张 130 dp | 一行 5 张 152 × 86 |
| 编辑桌面 | 页名 20 sp 主题色,底色 #0A0A0A | 页名 31 sp,底色同其他页 |
| 从手机添加 | 左上角标题,左右不对称 | 两栏,页名与三步说明整体居中 |

各页面的焦点账本没有动;只有确认页和引导换成了已有的 `GearMenu` / `CapsuleColumn`(原来各自养着一份同构的)。

## R136 动效:所有浮层同一套淡入淡出

- **打开 500 ms、关掉 400 ms、轻微放大 0.96;一摞里换层 300 ms 交叉淡化**——与设置外壳同一组常量(R113 定的),现在长按菜单、确认页、改名页、行图标、添加应用、三个选图页、扫码页、全屏预览、引导都走它(`OverlayStack`)。
- 焦点规矩沿用 R108:逻辑状态当场变、焦点同一帧落回;还在淡出的那一份是「残影」,不可聚焦、不收返回键、不回调。
- 图片网格翻页改用与首页 / 编辑页 / 所有应用同一根弹簧。
- 设置里光标换行,左侧说明 150 ms 交叉淡化;顶栏名字小胶囊的宽度与文字平滑过渡;滑块把手 120 ms 滑到新位置。
- **修掉一个闪烁**:从编辑页回到「布局」,原来首页先整屏露出再缩进预览框——亮壁纸下是 深 → 整屏亮 → 深。现在首页当场落在预览框里(`docs/screenshots/r136-edit-exit-frames.jpg`)。

## 我自己裁定的几条(Gordon 没看过,不对可回退)

- **确认页从小对话框改成整屏一页**:与长按菜单同一个样子,少一套视觉。代价:删一张图也要整屏换页,比小框「重」。
- **选图页不再透出首页**:原来 85 % 黑蒙版后面能隐约看到桌面;现在是不透明深色底,缩略图更大、一行多一张。
- **首次引导的语言那一步改成四颗胶囊**:按下即用这种语言进下一步(原来是先选、再按「继续」)。
- **淡入淡出时长直接用设置外壳那一组**(500 / 400 / 300 ms):没有另设更快的一组。菜单打开比改前慢半秒才完全显现,焦点不等它(打开那一帧就能按)。
- **所有应用页卡片名 13 → 14 sp**:与首页同一张卡同一个字号(R109 时这一页单独小了 1)。
