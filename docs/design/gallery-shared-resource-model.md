# Gallery 共享资源模型

2026-10-11 用户确认的概念裁定；本文件记录产品模型，不代表具体协议或实现方案已获批准。

## 已确定的规则

- 资源身份与使用场景分离。一张图片只有一个稳定ID、一份原图，可用于壁纸及屏保。视频仅用于屏保。
- 两个选择页按可用场景筛选同一资源目录，不维护两份同图清单，不为第二个场景复制原图或重新下载。
- 设为壁纸与加入屏保轮播是独立操作；设为壁纸不自动加入屏保，移出屏保不撤销壁纸。
- 图片已采用版本继续固定原图hash；清单更新不自动替换任一场景的采用版本。
- 两个场景任一仍引用该下载版本时，清理操作必须保护原图。
- 应用卡片保留独立用途与包名关联，不自动作为共享背景图。

## 涉及的现有结构

当前在线GalleryItem只有单一BuiltinKind，壁纸/屏保按kind互斥筛选；官方图库协议与发布器只支持图片，用户屏保播放器已支持视频。落实共享模型需修改素材清单、发布工具、客户端筛选及采用/删除保护；视频进入官方图库还需要对应下载和校验支持。

素材目录候选组织为images/、videos/、cards/，用途放在清单中。目录迁移、字段设计、旧清单/本地采用记录兼容与APK内置资源的改造范围需纳入后续具体方案，尚未执行。现有原图、稳定ID及revision-1产物保持原样；revision-1尚未发布。
