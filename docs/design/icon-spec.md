# UnitedU 1.0 图标 / Banner 尺寸规范

方向(Gordon 2026-09-23 定):图形是字母 **U**,形状像笑脸但一眼是 U;不要黑底/灰底,活泼或偏科技;文字只用 **UnitedU**。

## 1. 应用图标(自适应图标,Android 8+)

系统会把图标裁成**圆形、圆角方形或其它形状**(Google TV「Your apps」是圆形,76 dp 显示),所以图标由两层叠成,裁切由系统做。

| 项 | 规格 |
|---|---|
| 画布 | 正方形,**108 × 108 dp**;交付母版 **1024 × 1024 px** |
| 分层 | **背景层**(不透明,满铺画布,可以是纯色/渐变/图案)+ **前景层**(透明底 PNG,只有 U 图形) |
| 安全区 | U 图形必须落在画布中心 **直径 66 dp 的圆**内(1024 母版里 = 直径约 **626 px**);外圈会被裁掉或被系统做视差位移 |
| 可见区 | 中心 72 × 72 dp(1024 母版里约 682 px 见方),外侧每边 18 dp 只作出血,不放关键内容 |
| 背景层 | 必须铺满整个 1024 × 1024,不留透明、不画圆角(圆角由系统裁) |
| 格式 | PNG,sRGB;前景带 alpha |

从母版切出来的各尺寸(我来切):

| 密度 | 自适应图标每层(108 dp) | 传统图标(48 dp,老系统回退用) |
|---|---|---|
| mdpi | 108 px | 48 px |
| hdpi | 162 px | 72 px |
| xhdpi(A95L 是这档) | 216 px | 96 px |
| xxhdpi | 324 px | 144 px |
| xxxhdpi | 432 px | 192 px |

## 2. TV Banner

Android TV 的应用列表、索尼等桌面的应用行用它,是一张横图,**必须带应用名文字**(系统不在 banner 下面另写名字)。

| 项 | 规格 |
|---|---|
| 比例 | **16 : 9** |
| 系统尺寸 | **320 × 180 px @xhdpi**(= 160 × 90 dp);A95L 正好是 xhdpi,1:1 显示 |
| 交付母版 | **1280 × 720 px**(4 倍,缩到 320 × 180 仍锐利) |
| 内容 | 左 U 图形 + 右「UnitedU」字样;字在 320 × 180 下仍清楚(字高建议 ≥ 画面高 22%) |
| 边距 | 四周各留约 **8%**(1280 母版里左右 ~100 px、上下 ~58 px),有的桌面会给 banner 加圆角 |
| 背景 | 不透明、铺满;与图标背景层同一套配色 |
| 格式 | PNG,sRGB,无透明 |

## 3. 可选

- **单色版 U**(Android 13 主题图标用,TV 上基本用不到):1024 × 1024 透明底,纯黑 U,同样放在 66 dp 安全圆内。
- **GitHub / README 用大图**:512 × 512 PNG(与图标同图,圆角由展示方处理)。
