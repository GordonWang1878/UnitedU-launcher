## 我自己裁定的几条(Gordon 没看过,不对可回退)

- **说明区放左边而不是胶囊里**:胶囊宽 268 dp,一句话塞不进;左半屏本来空着。照 Android TV 两栏设置「右边说明焦点项」的做法,方向换成我们的左右布局。代价:页名整体上移约 50 dp。
- **「待机」改名「闲置画面」**:只改文案,存盘键 `idleAfterMs` / `idleContent` 不动,旧设置零迁移。
- **顶栏名字用小胶囊而不是直接写字**:直接写在壁纸上(加阴影也)在内置壁纸「夏日数码门」的蓝色光圈上看不清,小胶囊与药丸组同底色。
- **中文全角标点**:整份 strings.xml 的简 / 繁两份一起改;格式占位、网址、16:9、时间都不受影响(只动与汉字相邻的)。
- **引导删掉「跳过」**:第 1、3 步的「跳过」与主按钮是同一个回调,留着只会让人停下来想两颗有什么不同;第 2 步的「跳过」(从空桌面开始)是真的不同,保留。
