## 第三层 · 默认桌面页(「通用」→「设置默认桌面」,R74 外壳,R162 加第二颗)

左上路径「设置 · 通用」,页名「默认桌面」(En: Default Home App)。左边:页名下方一行「当前 + 默认桌面名字」,再下是说明段(`ShellNote`:光标换行时交叉淡化,按最高一段留位,页名不跳;纯展示、不可聚焦)。没有预览。

| 胶囊(简 / En) | 类型 | 什么时候画 | 左侧说明(简) |
|---|---|---|---|
| 去原生电视设置更改 / Change in Native TV Settings | 跳系统「主屏幕应用」页(没有这一页的固件见 `toast_home_settings_bounced`) | 常驻,缺省焦点 | 按主页(Home)键时打开的桌面。Android 只允许在原生电视设置里更改。 |
| 主页键接管 / Home Button Takeover(R162) | 跳系统无障碍设置页(无障碍服务「UnitedU 主页键接管」) | **条件行**:UnitedU 不是默认桌面,或服务已开着(得让人能关掉)才画;A95L(默认桌面、没开)不画,版式与 R162 前相同(模拟器上核对过) | 随状态四段,见下 |

胶囊下的状态小字与光标在这颗上时的左侧说明(简体;繁体用「主畫面鍵」):

| 状态(`HomeKeyStatus`) | 小字 | 左侧说明 |
|---|---|---|
| ON | 已开启 | 主页键接管已开启:按主页键回到 UnitedU。要还原,到原生电视设置的「无障碍」里关掉它。 |
| OFF | 未开启 | 这台电视把主页键交给了原厂桌面。开启主页键接管后,按主页键会直接回到 UnitedU,原厂桌面不用卸载。按确定前往原生电视设置的「无障碍」,打开「UnitedU 主页键接管」。 |
| NOT_RUNNING | 已开启,但没在运行 | 电视显示已开启,但服务没在运行(更新或重启后常见)。到原生电视设置的「无障碍」里关掉再打开,或重启电视。 |
| RESTRICTED | 这台电视不允许 | UnitedU 是用文件管理器或浏览器安装的,Android 13 起这台电视不允许打开它的无障碍服务。用电脑执行:`adb shell appops set com.uniteduone.launcher ACCESS_RESTRICTED_SETTINGS allow`,再到原生电视设置的「无障碍」里打开「UnitedU 主页键接管」;或先卸载、再用 adb 重新安装(会清掉桌面布局)。 |

状态判据(`HomeKeyState.status`):「开关开着」= 系统已启用的无障碍服务列表含本包;「在运行」= 服务心跳(这次开机连上过且没断)**且**系统此刻真的绑定着它;RESTRICTED = 没开且按安装来源推断受限(API ≥ 33,来源是本地 / 下载文件;见过一次就记住,开关开着那一刻清掉)。按下 RESTRICTED 那颗:先弹系统 Toast「这台电视不允许打开。返回后按左侧说明用电脑解锁,再试一次」,照样跳无障碍页(用户已用 adb 解锁的话还能继续)。从系统页回来重读状态,光标仍在这颗上。引导第 3 步同款(三颗:去原生电视设置更改 / 主页键接管〔条件〕/ 完成;受限时按下:系统提示 + 照样打开无障碍设置页,引导留在第 3 步)。截图:`docs/screenshots/r162/`。

## 关于页(第一层「关于」)

左边:标题「关于 UnitedU」、版本 `versionName (versionCode)`、状态文字、许可声明、项目地址;右边三颗胶囊(R164 起;Beta 包的版本号后标「Beta」):

| 胶囊 | 类型 | 说明 |
|---|---|---|
| 检查更新 | 动作 | 按状态变成「下载并安装」「安装更新」或进度文字(R74 起外壳样式);按当前更新通道读清单 |
| 更新通道 | 打开通道页(R164) | 右端值「稳定版」/「Beta」;进下面的「更新通道页」,返回落回这颗 |
| 恢复默认 | 打开确认页(R128 从「通用」挪来) | 确认层「设置 · 关于 / 恢复默认设置?」,说明「只重置这些设置。桌面上的应用、卡片图和你的照片都不会变。」:**取消** / 恢复;取消、返回、恢复都回到这颗 |

### 更新通道页(R164,关于页 →「更新通道」)

一个 `CapsuleColumn`,两颗胶囊(单测数到 2),二选一,当前项带 ✓,初始焦点落当前项;光标所在项的左侧说明换成对应一段(`ShellNote`,页名不跳):

| 胶囊 | 左侧说明 | 说明 |
|---|---|---|
| 稳定版 | 经过验证的版本,推荐大多数人使用。从 Beta 切回时会装回稳定版,布局与设置保留。 | 写 `updateChannel = stable`,回关于页并立即检查一次更新(已装版本比稳定版新时提示「可回到稳定版 x（布局与设置保留）」的回退包) |
| Beta | 先用上新功能,可能不太稳定。随时可以切回稳定版,不丢布局。 | 写 `updateChannel = beta`,回关于页并立即检查一次更新 |

「恢复默认」不动 `updateChannel`。

装更新走 PackageInstaller 会话 API(R162 ⑥;手机传 APK 传到的恰是 UnitedU 自己时同走这条)。会话失败而不是用户取消时(存储不足、签名不符、被策略拦下等)弹一条系统 Toast「更新没有装上(状态码)。可以在「关于」里重试」(`toast_self_update_failed`,按应用内语言);用户取消时关于页停在「安装中」、按钮可重试。
