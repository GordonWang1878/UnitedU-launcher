# UnitedU 设置页清单(2026-09-30 R130–R133 新手可读性之后,R134–R136 外观轮只改了字号 / 版式 / 动效,R140 只改了「自动开始」的说明;逐行对过 `SettingsModel.kt` / `ShellModel.kt` / `AboutScreen.kt` / `strings.xml`)

**规则(R128,Gordon 2026-09-29):每一页右边的胶囊最多 6 颗**——第一层、各组、子页、选项层、确认层、关于页都算,条件行按全部出现算。一页满了要加东西:先合并(像「闲置画面」子页),再加。单测 `SettingsPageLimitTest` 逐页数,超了当场红。

**规则(R131,2026-09-30):每一行都有一两句说明**,光标停在哪一行,外壳左边就写它是做什么的——没有预览的页写在页名下方(固定三行高,页名不跳),有预览的页写在预览框下方(有未保存的预览时让给「● 预览:…」)。动作行的动态小字(「自动关屏」去哪改)跟在说明下面、用主题色。单测 `CopyTest.everySettingsRowExplainsItself` 逐行查。

第一层 6 颗胶囊(顺序即显示顺序,默认焦点在第一颗);第二层是各组的行;「选项」列是点进去的第三层 / 滑块的取值。**粗体**是默认值。简体 / English 两种文案都列出,繁体见 `values-zh-rTW`(台湾用法:row = 列)。截图:`docs/screenshots/r131-settings-descriptions.jpg`、`r132-screensaver-group.jpg`。

## 第一层

左侧页名「设置」上方一行小字「UnitedU」(R148:品牌名从首页右上角时钟后面挪到这里,与其它页的路径小字同一个位置)。

| # | 胶囊(简 / En) | 说明小字(简) | 点进去 |
|---|---|---|---|
| 1 | 通用 / General | 语言、默认桌面、从手机添加、时钟 | 第二层「通用」 |
| 2 | 布局 / Layout | 编辑桌面、卡片大小、应用名、卡片色彩 | 第二层「布局」(左侧桌面预览) |
| 3 | 外观 / Appearance | 壁纸、主题色 | 第二层「外观」(左侧桌面预览) |
| 4 | 屏保 / Screensaver | 屏保图库、自动开始、系统屏保等 | 第二层「屏保」 |
| 5 | 电视设置 / TV Settings | 网络、画面、声音等电视自身的设置 | 跳安卓原生设置 |
| 6 | 关于 / About | 版本、检查更新、恢复默认 | 关于页:版本号 + 两颗胶囊「检查更新」「恢复默认」 |

中文第一层说明控制在一行(≤ 16 字,折行会把词拆开);英文按词折两行。

## 第二层 · 通用

5 颗常驻 + 1 颗条件行 = 最多 6 颗。

| 行(简 / En) | 类型 | 选项 / 右端 | 左侧说明(简) |
|---|---|---|---|
| 语言 / Language | 选项 | **跟随系统** / 简体中文 / 繁體中文 / English(En: System Default;R150 前是「简体 / 繁體」) | UnitedU 界面的语言,可以和电视系统不同。 |
| 默认桌面 / Default Home App | 打开页面 | 右端(放不下时在标签下)写现在的默认桌面名字;没选默认写「未设置」(R132) | 按遥控器的主页键时打开哪个桌面。设成 UnitedU,每次按主页键都会回到这里。 |
| 从手机添加 / Add from Phone | 打开页面 | 扫码页(R130:左三步说明、右二维码 + 手输地址) | 用手机扫码,把照片和视频传到电视,或给电视装应用。 |
| 闲置画面 / Idle Screen | 打开子页 | 摘要「3 分钟后 · 只留时钟」;进入闲置是「从不」时只写「从不」;摘要比单行值上限宽时挪到标签下面一行(R132) | 一段时间不按遥控器,桌面会淡去、只留时钟。在这里设定多久、留下什么。 |
| 时钟显示 / Clock Display | 选项 | 仅时间 / **时间与日期** / 时间、日期与星期(R149:「时间与日期」不再带星期,星期挪到第三档;另存 `showWeekday`) | 右上角的时钟显示哪些内容。 |
| 系统动画速度 / System Animation Speed | 条件行,跳开发者选项 | 只在电视动画缩放 ≠ 1× 时出现,显示当前倍数;组末行 | 电视的动画速度不是 1×,界面动画会变慢或变快。按确定前往开发者选项修改。 |

## 第三层 · 闲置画面(「通用」→「闲置画面」,R128 子页,R132 改名)

左上路径「设置 · 通用」,选项层路径「设置 · 通用 · 闲置画面」。没有预览。

| 行(简 / En) | 类型 | 选项 | 左侧说明(简) |
|---|---|---|---|
| 进入闲置 / Idle After | 选项 | 从不 / 1 分钟后 / **3 分钟后** / 5 分钟后 / 10 分钟后 | 多久不按遥控器,桌面就进入闲置画面。 |
| 闲置时显示 / Show When Idle | 选项 | **只留时钟** / 全黑 / 不变(En: Clock Only / Black / No Change) | 只留时钟:桌面淡去,留下右上角的时间。全黑:画面全部变黑。不变:桌面保持原样。 |
