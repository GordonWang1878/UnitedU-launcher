# UnitedU 设置页清单(2026-09-28,main `0e3b0a7` 之后;同日 R120 / R121 更新;2026-09-29 R127 屏保组加「关闭屏幕」、R128 每页 ≤ 6)

**规则(R128,Gordon 2026-09-29):每一页右边的胶囊最多 6 颗**——第一层、各组、子页、选项层、确认层、关于页都算,条件行按全部出现算。一页满了要加东西:先合并(像「待机」子页),再加。单测 `SettingsPageLimitTest` 逐页数,超了当场红。

第一层 6 颗胶囊(顺序即显示顺序,默认焦点在第一颗);第二层是各组的行;「选项」列是点进去的第三层 / 滑块的取值。**粗体**是默认值。截图:通用 `docs/screenshots/r128-general.jpg`、关于 `docs/screenshots/r128-about.jpg`。

## 第一层

| # | 胶囊 | 说明小字 | 点进去 |
|---|---|---|---|
| 1 | 通用 | 语言、默认桌面、手机传输、待机、时钟 | 第二层「通用」 |
| 2 | 布局 | 编辑分栏、卡片大小与标题、卡片色彩 | 第二层「布局」(左侧桌面预览) |
| 3 | 外观 | 壁纸、主题色 | 第二层「外观」(左侧桌面预览) |
| 4 | 屏保 | 屏保时间、图库、系统屏保、关屏 | 第二层「屏保」 |
| 5 | 系统设置 | 打开电视的 Android 设置 | 跳安卓原生设置 |
| 6 | 关于 | 版本、检查更新、恢复默认 | 关于页:版本号 + 两颗胶囊「检查更新」「恢复默认」(R128) |

## 第二层 · 通用

5 颗常驻 + 1 颗条件行 = 最多 6 颗(R128 前是 7 + 1 = 8)。

| 行 | 类型 | 选项 |
|---|---|---|
| 语言 | 选项 | **跟随系统** / 简体 / 繁體 / English |
| 设置默认桌面 | 打开页面 | 左:当前默认桌面;右:「在系统设置中更改」 |
| 手机传输 | 打开页面 | 扫码页(手机上传壁纸 / 卡片图 / 屏保 / 安装 APK) |
| 待机 | 打开子页(R128) | 右端是下面两行的值摘要,如「3 分 · 时钟」;点进去是第三层「待机」 |
| 时钟显示 | 选项 | 仅时间 / **时间与日期** |
| 系统动画缩放 | 条件行,跳开发者选项 | 只在电视动画缩放 ≠ 1× 时出现,显示当前倍数;R128 起是组末行 |

~~恢复默认~~ R128 挪进关于页。

## 第三层 · 待机(R128,「通用」→「待机」)

原「待机时长」「待机显示」两行原样搬进来(同一个 id、同一个选项层、同一个写入);左上路径「设置 · 通用」,选项层路径「设置 · 通用 · 待机」。没有预览。

| 行 | 类型 | 选项 |
|---|---|---|
| 待机时长 | 选项 | 关 / 1 分 / **3 分** / 5 分 / 10 分 |
| 待机显示 | 选项 | **时钟** / 全黑 / 不淡出 |

## 第二层 · 布局

| 行 | 类型 | 选项 |
|---|---|---|
| 编辑分栏 | 打开编辑页 | — |
| 卡片大小 | 选项 | 大(150 dp,一行 5 张)/ **中(122 dp,一行 6 张)** / 小(86 dp,一行 8 张)——R121:每档「一行正好完整显示」这么多张,聚焦最后一张完整卡时行不平移 |
| 卡片标题 | 选项 | **关** / 开 |
| 卡片饱和度 | 滑块 | 0–100%,每档 10%,**30%**(R120 从外观挪来) |
| 卡片亮度 | 滑块 | 50–100%,每档 5%,**75%** |
| 卡片透明度 | 滑块 | 0–60%,每档 10%,**0%**(光标所在卡恒不透明) |

## 第二层 · 外观

| 行 | 类型 | 选项 |
|---|---|---|
| 换壁纸 | 打开选图页 | 上「内置」4 张 / 下「我的」(＋ 从手机添加) |
| 壁纸模糊 | 滑块 | 0–50%,每档 5%,**0%** |
| 壁纸亮度 | 滑块 | −50% … +50%,每档 10%,**0%** |
| 主题色 | 选项(色点) | 白 / 香槟 / 雾蓝 / **淡紫** / 鼠尾草 |
| 跟随壁纸主色 | 选项 | **关** / 开 |

(卡片饱和度 / 亮度 / 透明度 R120 起在「布局」组。)

## 第二层 · 屏保

| 行 | 类型 | 选项 |
|---|---|---|
| 立即开始屏保 | 动作 | 轮播为空时只提示 |
| 屏保启动 | 选项 | 关 / 1 分 / **5 分** / 10 分 / 30 分 |
| 屏保轮播设置 | 选项 | **30 秒** / 1 分 / 5 分(换图间隔) |
| 屏保图库 | 打开图库 | 上「内置」(长按可关 / 开轮播)/ 下「我的」(照片、视频,可删) |
| 系统屏保 | 跳系统屏保页 | 右侧显示摘要,如「开 · UnitedU · 5 分钟」 |
| 关闭屏幕 | 先跳索尼「节能控制面板」,别家落系统设置首页(R127 / R127b) | 右侧显示系统 `sleep_timeout`:「无操作 24 小时后」/「无操作 30 分钟后」/「从不」,读不到写「查看」;下方小字随落点变:索尼「在 节能控制面板 → 处于非活动状态时关闭 里修改」/ Google TV 原生「在 系统 → 电源和能耗 → 关闭显示屏 里修改」/ 其他「在电视设置里找「关闭显示屏」或「休眠」」 |

## 关于页(第一层「关于」)

| 胶囊 | 类型 | 说明 |
|---|---|---|
| 检查更新 | 动作 | 按状态变成「下载并安装」「安装更新」或进度文字(R74 起外壳样式) |
| 恢复默认 | 打开确认页(R128 从「通用」挪来) | 确认层「设置 · 关于 / 恢复默认设置?」:**取消** / 恢复;取消、返回、恢复都回到这颗 |
