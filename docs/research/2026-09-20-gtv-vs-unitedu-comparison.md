## B. 需要决策的(逐条给出两边事实与取舍)

### B1. 焦点画法

- **Google**:**四种混用,按控件类型分**。顶栏 tab 选中=浅色实填 `rgb(232,234,237)`、聚焦未选中=中灰实填 `rgb(88,94,100)`;内容卡=**不缩放**,只在布局框外扩 5 dp 处画 2 dp 描边 + 柔光;圆形应用图标=**缩放 1.105 倍** + 2 dp 描边 + 柔光;面板磁贴与菜单项=**浅蓝实填**(`rgb(204,232,255)` / `rgb(228,243,255)`),文字转深色。
- **UnitedU**:**一种画法走天下** —— 聚焦 1.1 倍 + 3 dp 描边,无光晕。
- **取舍**:Google 的「四种混用」正是它看起来像 Google 的主要原因,比任何单个尺寸都关键;代价是实现与维护复杂度上升,而且我们的首页只有卡片一种内容,四种里有两种用不上。折中方案是取两种:卡片不缩放只描边 + 菜单/面板浅色实填。

### B2. 顶栏与时钟位置

- **Google**:常驻顶栏,左起 头像(40 dp)→ 药丸组 A(搜索 48 / Home 75 / Apps 69,高 36 dp)→ 22 dp 间隙 → 药丸组 B(屏保 32 / 快捷设置 32)→ **右侧时钟 + `Google TV` 字标**。焦点进内容行后整条折叠成一个向上箭头。
- **UnitedU**:右上 pill 组(设置 / 屏保);时钟是**左上 hero 大字 84 sp**,不在顶栏。
- **取舍**:照搬 Google 就得把 84 sp 大字时钟挪走、换成右上角小字 —— 那是 M8 美化轮特意做出来的招牌。搜索 / Apps tab / 账号三个位置我们没有对应功能(零推荐、无账号),照搬会留下空壳。

### B3. hero 大图位放什么

- **Google**:顶部 192 dp 高的 hero,放推荐内容;**焦点落到内容卡上时,该片的全幅剧照铺满整个屏幕**,左上叠标题 + 片源 + 评分元数据。
- **UnitedU**:壁纸全屏,应用行从下三分之一起。
- **取舍**:我们没有剧照也没有推荐。候选:①hero 位就放壁纸(等于现状,但行往下压);②放用户指定的一张大卡(某个应用的大图);③不要 hero,行直接从上面开始。

### B4. 邻行压暗 / 背景接管

- **Google**:内容卡聚焦时整页换成该片剧照,其余重度压暗;快捷设置面板浮出时背景同样重度压暗。
- **UnitedU**:**无邻行压暗**(明确设计),底部 scrim。
- **取舍**:压暗是 Google「聚焦感」的一半;但我们的背景是用户自己的壁纸,压暗等于把他选的图盖住。

### B5. 行尾 peeking

- **Google**:行尾卡被屏幕右缘正常裁切(实测第 6 张卡宽 74 px),焦点能正常走到它上面。
- **UnitedU**:**三档大小 = 每行 8 / 6 / 5 张整行放得下,不裁切**(M8 `HomeLayout`:卡宽 = (844 − 20×(N−1))/N)。
- **取舍**:照搬 peeking 要放弃「每行固定张数」这个已经调好的模型;好处是卡片尺寸固定、更像 Google,且暗示「右边还有」。

### B6. 主题色何去何从

- **Google**:没有主题色概念,焦点色固定浅蓝 / 浅灰。
- **UnitedU**:9 个预设 + 「跟随壁纸主色」,经 `LocalThemeColors` 驱动**全部界面**的 accent 与 highlight。
- **取舍**:保留主题色 = Google 的浅蓝实填换成主题色实填(功能保留、外观改 Google 样式,符合已定原则);砍掉 = 更像 Google,但删掉一个已完成的功能。

### B7. 字体

- **Google**:`Google Sans Flex`,**已在 google/fonts 走 SIL OFL 1.1,无 Reserved Font Name,可随软件打包**(已核实 `ofl/googlesansflex/OFL.txt` 与 `METADATA.pb`)。
- **坑**:**它没有中文子集**(subsets 只有 latin / latin-ext / vietnamese / math / symbols 等)。UnitedU 界面以中文为主,内置后只管英文数字,中文仍落系统字体 → 中英混排两套字形。
- **取舍**:①内置,接受中英混排;②不内置,全走系统字体(最省事、最一致,但少了 Google 的字形辨识度);③内置且中文配一个同气质的开源中文字体(如思源黑体 / 霞鹜文楷,体积 +8~20 MB)。

### B8. 应用图标的形状

- **Google**:`Your apps` 行是**圆形图标 76 dp**,间距 15 dp,聚焦放大 1.105 倍。
- **UnitedU**:应用是 16:9 卡片(banner 优先,无 banner 回落成图标居中 + 纯色底)。
- **取舍**:Google 把「应用」和「内容」用形状区分开(圆 vs 方);我们全是应用,没有这个区分需求,而且 16:9 卡片能显示 banner 图,信息量更大。

### B9. 菜单与设置面板

- **Google**:长按菜单 = 全屏黑底 + 左侧 app banner + 右侧整宽药丸动作(268×55 dp,全圆角,聚焦浅蓝实填);快捷设置 = 右侧浮出 sheet,2 列磁贴 124×55 dp,圆角 12 dp。
- **UnitedU**:齿轮菜单 / 长按卡片菜单(现有样式);设置页是两栏整屏。
- **取舍**:这两块照搬成本低、观感提升明显,且不牵动首页结构。

## C. 字号参考(Google 实测,cap height 反推)

| 用途 | Google |
|---|---|
| hero 标题 | ≈ 36 sp |
| 二级页大标题 | ≈ 32 sp |
| hero 副标题 | ≈ 16 sp |
| 行标题 | ≈ 14 sp |
| 应用名 | ≈ 14 sp |

UnitedU 现在唯一定死的是 hero 大字时钟 84 sp —— 比 Google 任何一处都大一倍以上,这是两套设计气质差异最大的地方。
