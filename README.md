# UnitedU

零广告、零推荐,只有你放上去的应用。

面向**国行无 GMS 的 Android TV**(索尼/小米/TCL 等买不到 Google 服务的电视)的开源桌面替代品。全程不联网,唯一的例外是你自己按「检查更新」的那一刻。不上架 Play 商店或国内应用市场——本项目只以 GitHub Release 的 APK 形式分发,需要自己下载安装。

包名 `com.uniteduone.launcher`,最低支持 Android 9(API 28)。首发版本号 `1.0.0-beta`(`versionCode 2`)。许可证与源码地址见文末。

## 安装

UnitedU 不在任何应用商店,需要自己把 APK 装到电视上,两种办法:

1. **电脑 + adb**:电视打开「开发者选项 → USB 调试」(或「无线调试」),电脑上执行

   ```bash
   adb install -r unitedu-<版本号>.apk
   ```

   `-r` 是为了覆盖安装同包名的旧版本,首次安装也可以照写不影响。adb 装包不经过「未知来源」这一关,电视上不会弹任何确认。

2. **手机传 APK,不用电脑**:如果电视上已经在跑 UnitedU(哪怕是别人帮你装的旧版本),打开「UnitedU 设置 → 壁纸 → 导入图片」,手机连上电视所在的 Wi-Fi,浏览器扫码或输入屏幕上的地址,切到「安装 APK」页签选文件上传,电视上会弹出系统安装器。这条路更适合装其他应用或以后手动更新,**装第一份 UnitedU 本身还是得靠 adb**(那时候电视上还没有 UnitedU 可以开导入页)。

「允许安装未知应用」只和第 2 种方式(以及以后在「关于」里装更新)有关:第一次由 UnitedU 把 APK 交给系统安装器时,电视会先跳到系统的「安装未知应用」设置页,给 UnitedU 打开开关、按返回回来,再在手机上重新上传一次即可。这个开关只需打开一次(每次安装时系统安装器自己的确认页照常会出现)。

## 设为默认桌面

装好之后 UnitedU 不会自动接管 HOME 键,需要手动切换:齿轮菜单 → UnitedU 设置 → 其他 → 设置默认桌面,先出现一张卡片显示当前的默认桌面,按「在系统设置中更改」跳到 Android 系统自带的「主屏幕应用」选择页,选 UnitedU 即可。这一步系统会记住,重启电视也不会变回去。

## 首次引导

第一次打开 UnitedU(全新安装,不是从旧版本升级)会自动出现三步引导,每步都能「跳过」:

1. **选语言**:跟随系统 / 简体 / 繁體 / English,选中立即生效。
2. **把已装应用铺上桌面**:列出电视上已安装、UnitedU 认识的应用(按视频 / 直播 / 音乐三行分好),「继续」就照这份清单放上桌面;跳过的话三行先空着,应用可以随时在「编辑分栏」里手动添加。
3. **设默认桌面**:跟上面「设为默认桌面」是同一个操作入口,这里是提前引导一次,跳过也不影响以后再设置。

老用户从旧版本升级不会看到这个引导。

## 上传图片(扫码)

想换壁纸、卡片图或屏保图片,不需要 U 盘或电脑:齿轮菜单 → UnitedU 设置 → 壁纸 → 导入图片,电视上会显示一个地址和二维码;手机(需要和电视连同一个 Wi-Fi)浏览器扫码或输入地址打开,按「壁纸 / 卡片图 / 屏保」三个页签分别上传、预览、删除图片。这个服务**只在「导入图片」页开着的时候运行,不设密码**,按返回键关闭页面就会一并停掉,离开这个页面局域网里其他设备就再连不上了。

## 长按卡片菜单

首页长按一张应用卡片(按住约 0.6 秒)弹出菜单:

- **打开应用**
- **卸载应用**——走系统卸载确认页,卸载完成后卡片自动消失
- **修改标题**——只改卡片上显示的名字,不影响应用本身
- **更改图标**——从图片库选一张 16:9 的图换掉卡片图,也可以在同一处恢复原图
- **移动位置**——跳转到「编辑分栏」并定位到这张卡,方便调整它在这一行里的顺序
- **从当前分类移除**——只是从这一行拿掉,应用本身不会被卸载

## 设置(两栏、实时预览)

齿轮菜单 → UnitedU 设置,左栏七个分组、右栏是该组的具体选项。遥控器的用法:**上下键**在当前这一栏里移动;左栏按**右键或确定键**进右栏;右栏里**左右键**直接改值,已经在最左一档时再按左键回左栏;带 ▸ 的动作行(换壁纸、导入图片、设置默认桌面、恢复默认)按**确定键**打开,按左键回左栏。**改了就能看到**:大部分选项一改,设置页背后的首页或预览就跟着变,不用退出设置确认效果。

| 分组 | 内容 |
|---|---|
| 布局 | 卡片大小(大/中/小,对应每行 5/6/8 张——卡片越大一行放得越少)、卡片标题开关、输入源行开关 |
| 壁纸 | 换壁纸、导入图片、轮播间隔(关/5 分/30 分/每天)、模糊、亮度(可调暗或调亮) |
| 主题 | 主题色(金/香槟/蓝/紫/石墨/绿六个预设)、跟随壁纸主色、主题化卡片(首页卡片去色后染成主题色) |
| 待机 | 待机时长(关/1/3/5/10 分)、待机显示内容(时钟/全黑/不淡出);焦点停在「待机显示」这一行时,背后的首页直接演示所选效果 |
| 时钟 | 显示日期开关(12/24 小时制跟随系统;星期几的文字跟随下面「语言」这一组的设置,选「跟随系统」时才跟随系统语言) |
| 语言 | 跟随系统/简体/繁體/English,选中立即生效并保留在语言这一行 |
| 其他 | 设置默认桌面、恢复默认(会弹确认框,焦点默认停在「取消」,误按确定键不会立刻清空) |

「恢复默认」只重置上面这些设置项,**不会**删除你放的应用分栏、改过的标题、卡片图或上传过的图片库。

## 检查更新

齿轮菜单 → 关于,顶部显示当前版本号(`versionName (versionCode)`)。UnitedU **不会自动联网检查更新**,只有按下「检查更新」按钮才会查一次,查完**一定会有结果显示**,不会点了没反应:

- 查询地址在构建时写进安装包,按顺序逐个尝试(可以配置腾讯云 COS 镜像在前、GitHub Release 在后;没有配置镜像的包只查 GitHub Release),前一个超时(8 秒)或失败就自动查下一个;
- 已是最新版本 → 提示「已是最新」;
- 有更新 → 显示新版本号和更新说明,按「下载并安装」;下载完先核对 SHA-256、包名、版本号和签名证书,全部通过才交给系统安装器(校验完成时如果你切到了别的应用、关于页还开着,回来后按「安装更新」再装;关掉关于页会取消这次下载);
- 网络查不通、返回的数据解析不出来、或者下载下来的包校验不过,分别给出对应的失败提示,不会一直转圈或什么都不提示。

第一次在这里装更新时,同样要先在电视上给 UnitedU 打开「安装未知应用」(见上文「安装」),然后回来重试。

## 回退到原桌面

不想用了随时能换回去,不需要卸载 UnitedU:齿轮菜单 → UnitedU 设置 → 其他 → 设置默认桌面 →「在系统设置中更改」,再次进入系统的「主屏幕应用」选择页,选回原来的桌面即可——这一步完全由 Android 系统接管,原厂桌面和 UnitedU 都还装在电视上,想换回来再选一次 UnitedU 就行。

## 反馈

电视上跑起来行为不对,用 adb 连上电视后看日志:

```bash
adb logcat -s UnitedU
```

欢迎在 [GitHub Issues](https://github.com/GordonWang1878/UnitedU-launcher/issues) 里反馈,附上这份日志、电视品牌型号和系统版本,问题会更容易定位。

## 征集其他品牌电视测试

目前只在 Gordon 自己的索尼 A95L(国行)和 Android TV 模拟器上验证过。国行没有 GMS 的其他品牌电视(小米、TCL、海信、当贝盒子等)如果装上试用,欢迎在 Issues 里留下机型、系统版本和使用体验——尤其是遥控器方向键、长按、返回键这类焦点相关的问题,这类问题在不同厂商的遥控器实现上差异最大。

## In short (English)

UnitedU is an open-source, ad-free Android TV launcher for GMS-less TVs (built and tested against a Chinese-market Sony A95L). It shows only the apps you put on it, never phones home except when you manually tap "Check for updates," and isn't distributed through any app store — grab the APK from [GitHub Releases](https://github.com/GordonWang1878/UnitedU-launcher/releases) and `adb install -r` it, or push a later APK from your phone via the in-app "Import images" page once UnitedU is already running.
